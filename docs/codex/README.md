## Rule

When documents disagree, use this priority:

1. Current source and focused tests for implemented behavior.
2. Approved V1.6 design spec for V1.6 scope and behavior.
3. V1.6 implementation plan for implementation sequence/interfaces.
4. `AGENTS.md` and `CLAUDE.md` for coding/agent workflow.
5. V1.3 design/plan for historical baseline behavior.
6. Condensed Codex docs for navigation and checklists.

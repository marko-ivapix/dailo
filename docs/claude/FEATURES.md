Native mobile clients and production guarantees are not supplied by this static web build.

1. `AGENTS.md`, `docs/codex/PRODUCT_BRIEF.md`, `V1_3_SCOPE.md`, `TASKS.md` and `ACCEPTANCE.md` describe the V1.3 baseline. Preserve historical semantics, but use `CLAUDE.md` and `CONTINUATION.md` as the current-version entry points and keep V1.4–V1.7 changes explicit.

## Modernization and the Capacitor app (2.0.0-alpha.2, 2026-10-09)

| Area | Behavior |
| --- | --- |
| Native app | The same files run in Capacitor 8 on iPhone and Android (`cloud.ivapix.dailo`). No service worker there; the page is packaged. Settings → Data shows "kept by the app" instead of the browser persistence question. |
| Files | Backups and attachments that do not open inline go through the system share sheet; cancelling the sheet is reported as a cancelled export, not as a backup. Only images, PDF and plain text open inside the app (`Core.attachmentOpensInline`). |
| Links | http(s) links open in the system browser sheet, `mailto:`/`tel:` in the system apps; the tester guide opens online. |
| Android Back | Closes the top sheet, menu, popover, inline editor or dialog like Escape; otherwise goes back, and from the first screen minimizes. A running reset or restore ignores it. |
| Durable copy | The app writes the canonical metadata to `Library/dailo/state.json` (1 s after saves, at once on pause) and restores it only when the WebView store has lost the key, with a toast. Habit logs, goal history and files are not in that copy. |
| Reminders | Phone notifications for tasks, goals and habits for the next 14 days (at most 60), rebuilt after saves, habit check-ins, start and resume; a tap opens the item unless a dialog is open; the system question comes once, when there is first something to notify; Android without exact alarms gets inexact reminders and a Settings "Tačno vreme" row. "Odloži za večeras" is not offered from 21:00 and "Kasnije danas" not when it would be tomorrow (web too). |
| Mobile layout | Popovers survive the keyboard; heights use `dvh`; 16 px fields on touch screens; 44 px targets on touch screens; the toast sits above the bottom navigation. |
| Transfer | On a fresh install the app's Today offers "Uvezi rezervnu kopiju" / "Prijava" / "Ne treba"; a first sync from untouched examples takes the account data after a recovery copy. |
| Data fixes (all platforms) | Sync never deletes record types it does not know; pulled deletions no longer stop sync on dangling links; completion and history days are local days (00:30 counts as today). |

Known gaps from the audit, not in this round: tokens in localStorage (Keychain/Keystore later), color validation, export limits, fired-reminder markers still synced (R-3), render/save cost at large data (Q-1), focus after re-render (A-2). Open questions for the user: habit weekly-target history semantics, daily-habit reminders after a check-in, Search debounce/cap.

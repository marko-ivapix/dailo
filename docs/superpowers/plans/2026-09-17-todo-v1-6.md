# Dailo V1.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver V1.6 as six independently testable blocks that make Today faster, deepen Goals/Habits, add time-aware Calendar planning, enrich Notes/Resources, improve templates/personalization, and finish with safe backup and compact polish.

**Architecture:** Keep the V1.5 static local-first architecture. Add pure projection/helpers to `js/core.js`, keep UI rendering in the existing focused UI modules, and store only canonical records/preferences; all Today, Calendar, and analytics surfaces remain derived views. Additive migration and backup serialization are the only cross-cutting data changes.

**Tech Stack:** HTML, CSS, vanilla JavaScript, localStorage, IndexedDB, Node built-in test runner, existing Python DOM/static checks, JSZip for ZIP backup.

**Spec:** `docs/superpowers/specs/2026-09-17-todo-v1-6-design.md`

## Global Constraints

- Preserve V1.5 behavior unless the V1.6 spec explicitly changes it.
- Do not change global Search scope, ranking, or interaction behavior.
- Do not add bulk-selection or bulk-action UI.
- Keep local-first storage, V3 compatibility, and recovery/Undo semantics.
- Preserve Dailo dark technical branding and compact density tokens.
- Do not launch isolated Chromium or open the user’s personal Chrome during implementation.
- Each task follows failing test → minimal implementation → focused test → regression test → commit.

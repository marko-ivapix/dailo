# Dailo V1.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement V1.4 as a faster, clearer local-first daily-planning workspace while preserving all V1.3 behavior.

**Architecture:** Keep the current vanilla JavaScript modules and use `js/core.js` for shared date/derivation rules, `js/*-ui.js` for focused rendering, and `js/app.js` for orchestration/persistence. Add only optional normalized fields unless a migration is required; do not add dependencies or a framework.

**Tech Stack:** Vanilla JavaScript, HTML, CSS design tokens, IndexedDB/storage facade, existing Node test suite, isolated preview browser.

**Spec:** `docs/superpowers/specs/2026-09-17-todo-v1-4-design.md`

## Global Constraints

- Preserve the Today-first workflow, dark branding/design system, no-gradient language, and current module split.
- Preserve global Search behavior and do not add bulk actions.
- Keep the prototype local-first and dependency-free.
- Preserve V1.3 migration, ZIP backup/import, safety snapshots, typed RESET/RESTORE, and delete/Undo behavior.
- Use the isolated worktree and isolated preview browser only; never open the user’s personal Chrome.

## File map

- `js/core.js`: shared date windows, cross-view derivation, progress and conflict calculations.
- `js/app.js`: state normalization, routing, persistence, modal orchestration, and cross-module actions.
- `js/tasks-ui.js`: Task rows and Task Properties UI.
- `js/calendar-ui.js`: Week/Month/Day Detail UI and planning interactions.
- `js/goals-ui.js`: Goal detail, links, milestones, reminders, history.
- `js/habits-ui.js`: routines, monthly tracker, check-ins, streaks, analysis.
- `js/knowledge.js`: Notes and Resources forms, relations, tags, attachments.
- `css/styles.css`: responsive layout, touch targets, focus states, empty/loading/error states.
- `js/backup.js`, `js/storage.js`: backup validation, migration, attachment and recovery safety.
- `tests/core-v1-3.test.js`, `tests/storage-v1-3.test.js`: regression coverage for shared rules and persistence.

# Dailo V2.0-b implementation plan — Capacitor shell

**Spec:** `docs/superpowers/specs/2026-10-08-todo-v2-0-design.md`, section A and phase 2 (approved 2026-10-08)
**Ledger:** `docs/superpowers/progress-v2-0b.md`
**Baseline:** V2.0-a (`2.0.0-alpha.1`) on `ccr-95f6062b-lgg2fr`
**Version:** `APP_VERSION` `2.0.0-alpha.2`; native marketing version `2.0.0`, build 1.

The same static web app runs inside Capacitor on iPhone and Android. No bundler: a copy step builds `www/` from the files the service worker already precaches.

## Step 1 — Packaging

- [x] **`package.json`:**
  - private, with exact versions: `@capacitor/core`, `ios`, `android` and `cli` 8.5.3, `local-notifications` 8.3.1, `app` 8.1.2, `filesystem` 8.1.4, `share` 8.0.3;
  - scripts `build` (copy to `www/`) and `sync` (build, then `cap sync`);
  - no `"type": "module"`, so the CommonJS tests keep working;
  - `package-lock.json` committed.
- [x] **`capacitor.config.json`:**
  - `appId` `cloud.ivapix.dailo`, `appName` "Dailo", `webDir` `www`, background `#0F1114`;
  - iOS `contentInset: never` (the CSS handles safe areas);
  - Android `SystemBars` with `insetsHandling: css` and `initialViewportFitValueHint: cover`;
  - Local Notifications small icon `ic_stat_dailo` and icon color.
- [x] **`tools/build-www.mjs`:** copies exactly `SHELL_FILES` from `sw.js` into `www/` (or into a given directory), after emptying it. `sw.js` itself is not copied, because the native app needs no service worker.
- [x] **`vendor/capacitor/capacitor.js`** (from `@capacitor/core` 8.5.3, MIT, with `LICENSE`):
  - loaded first in `index.html` and precached;
  - on the web it only reports the platform `web`; in the app it provides `Capacitor.registerPlugin` for the native plugins.
- [x] **Native projects:** `ios/` (Swift Package Manager, iOS 15+) and `android/` (API 24+, target 36), generated with `npx cap add`. `.gitignore` covers `node_modules/` and `www/`.
- [x] **Failing tests first** (`tests/native-v2-0b.test.js`): config and pinned versions, the `www/` file list, both native projects and their ids.

## Step 2 — Native bridge (`js/native.js`)

- [x] **`Core.upcomingReminders(state, now, { days = 14, limit = 60 })`** (pure). It returns the next reminder moments, sorted, at most 60 (iOS keeps 64 pending):
  - **tasks:** `reminderAt` on open tasks;
  - **goals:** active goals' reminder moments up to the target date;
  - **habits:** enabled reminder times on scheduled days, with snoozes and a met weekly target respected for the current week;
  - fired moments are skipped.
- [x] **`DailoNative`:**
  - `isNative`;
  - `scheduleReminders(list)`: cancel the previously scheduled ids, then schedule with stable 31-bit ids, title, body and a route in `extra`;
  - permission state and request;
  - `shareFile(blob, name)`: Filesystem cache, then the share sheet;
  - App `resume` and notification-tap listeners.
- [x] **`app.js` wiring:**
  - no service worker in the app;
  - `environmentInfo().standalone` is true;
  - persistence state `native`;
  - the Settings notification button uses native permissions;
  - reminders are rescheduled 2 seconds after a save, on start and on resume;
  - resume also runs `checkReminders` and `scheduleSync`;
  - a notification tap opens its route;
  - `downloadBackup` uses the share sheet;
  - the guide link opens the online `uputstvo.html`.
- [x] Catalog entries; untranslated-text and class audits.

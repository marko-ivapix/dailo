# V1.3 Next Steps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the most visible V1.3 prototype workflows in dependency order, then package a stable demo for manual testing.

**Architecture:** Keep the existing static HTML/JavaScript architecture and current module split. Each feature stays in its focused `js/*-ui.js` module, while shared calculations remain in `js/core.js`; `js/app.js` remains the orchestration layer. Prefer small additive changes over broad rewrites.

**Tech Stack:** Vanilla JavaScript, HTML, CSS design tokens, IndexedDB/storage facade, existing local test fixtures.

**Spec:** `docs/superpowers/specs/2026-09-15-todo-v1-3-design.md`

## Global Constraints

- Preserve V1.2 behavior unless V1.3 explicitly changes it.
- Do not change global Search behavior.
- Do not add bulk actions.
- Preserve the existing branding, dark design system, spacing, typography, and no-gradient visual language.
- Use the isolated V1.3 worktree and the isolated preview browser only.
- Keep prototype work simple: no new dependencies, no premature architecture rewrite.

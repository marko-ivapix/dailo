# R102 — Pretraga: without diacritics and across scripts everywhere, and a command palette

**Date:** 2026-10-15 · **Status:** the user's request from the review list ("sve odradi osim ciljeva"). For Pretraga the plan read: "Pretraga bez obzira na kvačice i ćirilicu svuda; paleta komandi (Ctrl/Cmd+K); globalni redosled i obim ostaju." · **Release:** `2.0.0-alpha.130`. No data-model change.

## One fold for every search

`Core.searchFold(value)` drops what should not matter:
- case;
- diacritics (č, ć, š, ž → c, s, z);
- the script: Cyrillic reads as Latin through the existing `cyrillicToLatin`;
- "đ", "dj" and "ђ" all read as "d", so "Đorđe", "Djordje", "Dordje" and "Ђорђе" find each other.

Both the words and the text pass through it. It replaces four different rules:

| Where | Before | Now |
| --- | --- | --- |
| **Global Search** (`Core.searchItems`) | case only | `searchFold`. The ranking is unchanged (title equal, title contains, notes contain; projects by name), and so is the scope (tasks and projects). |
| **The journal search** | case and diacritics, "đ" as "d" | `searchFold`, which adds Cyrillic |
| **Beleške and Resursi** (every word, any order) | case and diacritics | `searchFold`, which adds Cyrillic |
| **The pickers' search fields** (project, tag, linked items) | case only | the rows carry folded names, and the field folds what is typed |

## The command palette

- **Opening:** Ctrl+K (Cmd+K on a Mac) opens it, when no window is open and nothing is being typed. If the user gave that combination to another shortcut in Podešavanja, the shortcut wins.
- **The module:** `js/palette-ui.js`, loaded after `sidebar-ui.js` and before `app.js`, and precached in `sw.js`.
- **The list:**
  - **actions:** Novi zadatak, Novi projekat, Nova navika, Nova beleška;
  - **screens:** Danas, Inbox, Zadaci, Kalendar, Navike, Predstojeće, Kad stignem, Projekti, Ciljevi, Oblasti, Redovne obaveze, Beleške, Resursi, Dnevnik, Oznake, Sačuvani prikazi, Nedeljni pregled, Završeni zadaci, Arhivirani projekti, Podešavanja, Nalog.
  - Each row names its kind (Radnja, Ekran).
- **Typing:** it filters by every word, folded ("kalen" finds Kalendar, "навике" finds Navike). With words typed, the last row is **Pretraži „…“**, which opens Search with those words. So the palette adds no search of its own, and global Search keeps its ranking and scope.
- **Keys:** ↑ ↓ move the choice (`aria-activedescendant` on the combobox field), Enter runs it, a click runs a row, and Escape closes it as every window does.
- **Redrawing:** typing redraws only the list, so the field keeps its focus.
- **Search:** `openSearch(query = '')` opens Search with words; called with none, it opens as before.

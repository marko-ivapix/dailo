# R81 — Šta je novo

**Date:** 2026-10-15 · **Status:** point 5 of the outside review ("Dodajte ekran „Šta je novo“"), accepted by the user ("Sve se slažem…"). · **Release:** `2.0.0-alpha.108`. No data-model change; one new device-local key.

## The change

- **`novo.html`:** a public Serbian page in the style of `pitanja.html`. It has the R57 head and preview, no script, and the "Otvori Dailo" link.
  - The recent changes are grouped by day, newest first:
    - **15 October:** R74–R81, alpha.101–108, with the version range named;
    - **14 October:** R72–R73;
    - **13 October:** R59–R71.
  - The changes are written for users, not developers, with no gendered forms.
  - It links to the guide and the FAQ.
- **The app:**
  - **Podešavanja → Pomoć** gets "Šta je novo · Pogledaj novo" after Česta pitanja (`data-whats-new`).
  - **`Release.WHATS_NEW_URL`:** the phone app opens the page online, like the other public pages.
- **After an update:**
  - `announceUpdate()` runs after the start-up load, unless the start restored data from the phone's copy.
  - The device-local key `dailoSeenVersion` keeps the version this device last started. It is outside state, backups and sync, and listed in CLAUDE.md.
  - When that version differs from `APP_VERSION`, one toast says "Dailo je ažuriran na <version>." with the link "Šta je novo".
  - A first start, or the first start with this step, only remembers the version. Blocked storage stays quiet.
- **The toast:** an information toast can now carry a link (`{ href, label }`) as well as the R36 task button (`a.toast-action`).
- **The site:** `tools/check-links.mjs` checks the page.
- **Updating the page:** each later step that users notice adds a line to the newest day. The newest version must be named on the page, which `tests/whats-new-r81.test.js` checks while it pins the version.

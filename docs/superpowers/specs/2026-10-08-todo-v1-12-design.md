# Dailo V1.12 — Duration and time-blocking

**Status:** approved scope (user request 2026-10-08, "Odradi sve tačke"; roadmap Phase 4 "Duration + time-blocking").
**Baseline:** V1.11 (Weekly review).
**Roadmap:** `docs/superpowers/plans/2026-10-07-release-roadmap.md`, Phase 4.

## Goal

See a day as a schedule:
- what is planned at which hour;
- what still has no time, and give it one in a tap;
- how much planned work fits into the day.

## Existing behavior (kept)

- `durationMinutes` and `plannedTime` on tasks, edited in Task Properties. V1.10 added Quick Add duration syntax.
- `Core.getTimedTaskBlocks` (open timed tasks with a duration, overlap flag) and `Core.calendarTimeBlocks` (timed tasks of a date) feed the week view and Day detail. They are unchanged.
- The week and month views, the Day detail dialog and the existing drag targets are unchanged. Calendar visibility toggles still hide tasks.

## Design

### A. Core (pure)

- **`Core.daySchedule(tasks, date, { defaultMinutes = 30 })`** returns the scheduling data for one day:
  - `blocks`: timed tasks planned for `date`, as `{ task, startMinutes, endMinutes, durationMinutes, estimated, conflict }`. A task without a duration uses `defaultMinutes` and is marked `estimated`. `conflict` compares open blocks only. Completed tasks are included without conflicts;
  - `unscheduled`: open tasks planned for `date` without a time, sorted by Today order then title;
  - `range`: `{ startHour, endHour }`, 6 and 24 by default (rows 06:00–23:00). The start moves earlier for a block before 06:00; the end stays 24, so a block running past midnight extends below the last row.
- **`Core.dayLoad(tasks, date)`** returns `{ minutes, withDuration, withoutDuration }` for open tasks planned for `date`.
- **`Core.dailyCapacityMinutes(settings)`** returns `settings.dailyCapacityMinutes` when it is an integer from 0 to 1440, otherwise 360 (6 h). 0 turns capacity off.

### B. Calendar day view

- **View switch:** "Dan" / "Nedelja" / "Mesec". `state.ui.calendarView` accepts `day`. The previous and next buttons move by one day; the "Today" button keeps working.
- **Capacity bar:** when capacity is on and at least one open task planned that day has a duration, a bar shows "Planirano {planned} od {capacity}". It turns into a warning when the day is over capacity.
- **"Bez vremena" list:** each task without a time has a native time input, labelled with the task title. It reuses the existing `data-task-time="plannedTime"` change handler, so choosing a time sets `plannedTime`. A planned time is removed in Task Properties, as before; dragging a block onto the list changes only the date. On desktop the rows are also draggable (existing `data-calendar-drag="task"`).
- **Hour grid:**
  - one row per hour, each a drop target (`data-calendar-time="HH:00"` inside `data-calendar-date`); the existing calendar drop handler plans the task for that day and hour;
  - blocks are positioned by start and length, open the task on click, and show the time range;
  - CSS classes mark overlapping blocks (`has-conflict`), a block without a duration (`is-estimated`, dashed) and done tasks (`is-completed`).
- **Empty day:** "Nema planiranih zadataka za ovaj dan." plus a "Dodaj zadatak" button (`calendar-new-task`) next to the header's existing "Dodaj".

### C. Capacity on Today

- **Where:** the Today focus strip shows the load next to the open count, for example "2 h 30 min / 6 h" (`data-today-capacity`).
- **When:** capacity is on and at least one open task planned for today has a duration.
- **Over capacity:** the item gets `is-over` and an accessible label ("Preko kapaciteta").
- **Visibility:** the item belongs to the focus strip, so it is hidden when the Today summary strip is turned off.
- **Overlaps:** overlapping blocks are drawn on top of each other at full width; the conflict border marks them.

### D. Settings and persistence

- **Setting:** Settings → General → "Dnevni kapacitet" offers Isključeno / 2 / 4 / 5 / 6 / 7 / 8 / 10 / 12 h and stores `settings.dailyCapacityMinutes`.
- **Import:** backup import rejects a value that is not an integer from 0 to 1440.
- **Unchanged:** no schema change; a missing value means 6 h.

### E. Quick Add duration chip

- **Chip:** "Trajanje" (`ph-timer`) in the Quick Add property chips opens a popover with 15 / 30 / 45 / 60 / 90 / 120 min and "Ukloni".
- **Precedence:** the chosen value is explicit and wins over the parsed one, per V1.10 precedence.

### F. Out of scope

- A multi-day hour grid (the week stays a list).
- Resizing blocks by dragging.
- Scheduling habits or goals on the grid.
- Automatic scheduling.
- External calendars.

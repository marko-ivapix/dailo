**Date:** 2026-10-16 · **Release:** `2.0.0-alpha.139` · No data-model change. · **Plan:** `docs/superpowers/plans/2026-10-12-app-js-modules.md` (part 1, "drag").

- The answer recommended continuing the module plan, one part per release, starting with drag. The user said: "da, kreni sa prvim delom".

## The change

Nothing changes for the user. The code moves:

- **`js/drag-ui.js`** is a new domain module named `drag` (about 400 lines). It takes from `js/app.js`, unchanged:
  - the task swipes (`resetTaskSwipe`, `handleTaskSwipeStart`, `handleTaskSwipeMove`, `finishTaskSwipe`, `handleTaskSwipeClick`);
  - touch reordering (`REORDER_ROWS`, `sameReorderList`, `handleTouchReorderStart` … `cancelTouchReorder`, `blockTouchScroll`);
  - the calendar's hold-and-drag of R91 (`CALENDAR_TOUCH_SOURCES`, `CALENDAR_TOUCH_TARGETS`, `handleCalendarTouchStart` … `cancelCalendarTouch`);
  - the Navike week swipe of R44 (`handleWeekSwipeStart`, `finishWeekSwipe`, `handleWeekSwipeClick`);
  - mouse drag and drop (`handleDragStart`, `handleDragOver`, `handleDragLeave`, `handleDrop`, `handleDragEnd`, `cleanupDrag`) with its drops on the sidebar and on days (`sidebarDropTarget`, `dropTaskOnSidebar`, `moveTaskToProject`, `dropTaskOnDay`);
  - the long press (`handleLongPressStart`, `runLongPress`, `cancelLongPress`, `handleLongPressClick`);
  - their state (`dragState`, `taskSwipeState`, `weekSwipe`, `suppressWeekSwipeClick`, `suppressTaskSwipeClick`, `touchReorder`, `calendarTouch`, `longPressTimer`, `longPressFired`).
- **Two new optional entries in the module contract:**
  - `attach(ctx)`: `attachEvents` calls it once on every module that has it, as its first line. The drag module takes the helpers it needs from `ctx` into its own variables and wires the same 30 listeners in the same order as before.
  - `isDragging()`: `syncWaiting` asks `callDomainHook('isDragging')` where it read `dragState`, so a pulled sync still waits while a row or card is dragged.
- **`js/app.js`** keeps:
  - `reorderTasks`, `reorderSubtasks` and `dropGroup`, because the "Pomeri gore / dole" buttons and the subtask editor use them too;
  - the glue in `attachEvents` and `syncWaiting`;
  - one new line in `domainContext()`: `haptic`, `toggleComplete`, `reorderTasks`, `reorderSubtasks`, `dropGroup`, `receiveAttachmentFiles`, `addTaskToToday`, `moveTaskToTomorrow`, `quickAddDirect`, `setMobileQuickAddOpen`, `routeQuickAddContext`, `callDomainHook`.
  - It shrinks from 7,801 to 7,416 lines.
- **Loading:** `index.html` loads the module after `js/palette-ui.js` and before `js/app.js`, and `sw.js` precaches it, so `npm run build` copies it into `www/`.
- **Tests:** `tests/support/source.js` lists the module in `APP_FILES`. Older tests read the moved functions through `functionSource` and the listeners from `attach`, with the same assertions:
  - `redesign-r2`, `-r23`, `-r25`, `-r33`, `-r36`, `-r44` and `-r47d`, `phone-feel-r62`, `calendar-r91`;
  - the two sync harnesses (`sync-app-v2-0a`, `redesign-r40`) answer `isDragging` from their `dragState` stub;
  - `search-r102`: the load order with the new script;
  - `tests/ui-v1-6-calendar.py`: reads the drop code from the module.
  - Each changed line has an R110 comment.
- **Pages:** Šta je novo names `2.0.0-alpha.139` in the 16 October range; there is no new line, since nothing visible changed.

## The workflow

`.github/workflows/ci.yml` runs on every push to any branch, on pull requests and by hand (`workflow_dispatch`). It has read-only permissions, and a newer push cancels the older run on the same branch.

| Job | Steps |
| --- | --- |
| `web` | Node 22 with the npm cache, `npm ci`, `npm run verify` (syntax and the Node suite), `npm run smoke` (jsdom boot), Python 3.12 and `npm run check:python` |
| `android` (after `web`) | JDK 21 (Temurin) with the Gradle cache, `npm ci`, `npm run cap:sync`, `./gradlew assembleDebug --no-daemon` in `android/`; the APK is uploaded as the artifact `dailo-debug-apk` and kept 14 days |

## One command for the Python checks

`npm run check:python` runs `tools/check-python.py`, which needs no packages and never launches a browser:
- AST parsing of `tests/*.py` and `tools/*.py`;
- the browser-path adapter unittest;
- the regression-registry contracts;
- the static browser contracts (`--dry-run`).

It reports each check and exits with an error if any fails. `docs/claude/TESTING_AND_RELEASE.md` lists it next to `verify` and `smoke`.

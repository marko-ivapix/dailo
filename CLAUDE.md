## Project in one paragraph

Dailo is a desktop-first, dark, local-first personal productivity prototype built with static HTML, CSS and vanilla JavaScript. Its workflow is **Capture → Organize → Plan → Complete**. `localStorage` holds compact application metadata; IndexedDB holds attachments, Habit logs, Goal history and recovery snapshots. Since V1.9 the UI is Serbian (Latin script), and the app installs to the Home Screen and starts offline as a PWA. V2.0-a adds optional Supabase sync with e-mail one-time-code sign-in; it is off until `js/sync-config.js` has the project URL and public key, and without an account the app stays fully local. Since 2.0.0-alpha.2 the same files also run inside a Capacitor 8 app for iPhone and Android (`capacitor.config.json`, `ios/`, `android/`); `js/platform.js` is the only code that knows whether it runs on the web or natively (files, links, Back, pause/resume, reminders as phone notifications, a durable copy of the metadata).

## Safe default commands

```bash
npm ci                 # jsdom for the smoke test, Capacitor for the native projects
npm run verify         # syntax of every JS file + the Node suite
npm run smoke          # boots index.html in jsdom: create a task, Back, reopen, find it
npm run build          # copies the precached shell into www/
npm run cap:sync       # build + npx cap sync (iOS and Android projects)
python3 -m http.server 8080
```

Without `npm ci`, `node --test "tests/*.test.js"` and `node tools/check-syntax.mjs` still work (only the smoke test and `cap` need `node_modules`).

Do not launch an isolated Chromium or open/modify the user's personal Chrome unless the user explicitly asks for that browser action. Native visual/browser acceptance is separate from the local automated suite.
